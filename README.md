# MELTT 홈페이지

빌드나 패키지 설치가 필요 없는 정적 홈페이지입니다.

## VS Code에서 바로 보기

1. VS Code에서 이 폴더를 엽니다.
2. `F5` 또는 `Ctrl+F5`를 누릅니다.
3. 실행 구성이 표시되면 **MELTT 홈페이지 미리보기**를 선택합니다.

로컬 서버가 자동으로 실행되고 Microsoft Edge에서 `http://127.0.0.1:4173`이 열립니다.

## 터미널에서 보기

```powershell
npm start
```

출력된 주소를 브라우저에서 열면 됩니다. 외부 npm 패키지는 사용하지 않습니다.

## 주요 파일

- `index.html`: 페이지 콘텐츠와 구조
- `styles.css`: 반응형 디자인과 애니메이션
- `app.js`: 모바일 메뉴와 구매 알림
- `assets/`: 홈페이지 이미지
- `server.mjs`: 의존성 없는 로컬 미리보기 서버

## 모바일 타이포그래피 가이드

모바일 화면(`800px` 이하)은 아래 크기 체계를 사용합니다.

- 12px: 섹션 라벨, 배지, 캡션, 보조 정보
- 14px: 설명·카드 본문·푸터·버튼
- 16px: 기본 본문과 주요 설명
- 20px: 카드 제목과 가격
- 32–40px: 섹션 제목
- 40–48px: 히어로 및 CTA 제목

본문 줄간격은 `1.6–1.65`, 대형 제목은 `1.08–1.14` 범위로 유지합니다. 모바일에서 12px 미만의 텍스트와 48px를 초과하는 제목은 사용하지 않습니다. 모든 텍스트는 기울임 없이 정자체로 표시합니다.

## 전체 타이포그래피 제한

- 모든 화면에서 가장 작은 보조 문구는 12px 이상을 유지합니다.
- 일반 본문은 14–16px, 카드 제목은 20–24px를 사용합니다.
- 섹션 제목은 34–58px 사이에서 반응형으로 조절합니다.
- 히어로와 CTA를 포함한 모든 텍스트의 최대 크기는 58px입니다.
